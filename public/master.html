방법 1 (추천) · 서버가 메일함을 직접 확인 — 앱 비밀번호

  1. 인증 메일이 오는 Gmail(예: ad.bodacompany@gmail.com)로 로그인해 2단계 인증을 켭니다.
  2. 앱 비밀번호 페이지에서 이름(예: 과제보드)을 넣고 만들기 → 나온 16자리를 복사합니다.
  3. Railway → 서비스 → Variables 에 INBOX_IMAP_USER = 메일 주소, INBOX_IMAP_PASSWORD = 16자리 를 추가하고 저장(자동 재배포).
  4. 1~2분 뒤 이 창 맨 위에 ✅ 연결됨이 보이면 끝입니다. 30초마다 확인하며, OpenAI 메일만 읽기 전용으로 가져옵니다(읽음 표시도 바꾸지 않음).

가져올 메일 조건은 INBOX_IMAP_QUERY(Gmail 검색어, 기본 from:openai.com newer_than:1d)로 바꿀 수 있습니다. 그만 쓰려면 Google 계정에서 그 앱 비밀번호만 삭제하면 바로 끊깁니다.

방법 2 · Google Apps Script

계정에 따라 "차단된 앱"으로 막힐 수 있습니다. 그때는 방법 1을 쓰세요.

  1. script.google.com 에서 새 프로젝트를 만듭니다. (인증 메일이 오는 Gmail 계정으로 로그인)
  2. 기존 코드를 지우고 아래 코드를 붙여넣기 → 💾 저장.
  3. 위쪽 함수 목록에서 setup 을 고르고 ▶ 실행 → 권한 검토 → 계정 선택 → (확인되지 않은 앱 경고가 나오면) 고급 → 이동 → 허용.
  4. 이제 1분마다 자동으로 확인합니다. 메일 도착 후 화면에 뜨기까지 1~2분 걸릴 수 있습니다.

가져올 메일 조건은 코드 맨 위 QUERY(Gmail 검색어)로 바꿀 수 있습니다. 이 사이트에는 조건에 맞는 메일만 전송되고, 뒤 자동 삭제됩니다.
